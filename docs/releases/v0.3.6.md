**EN — SC Telemetry Deck 0.3.6** — weapons, weapon group and gimbals on the Stream Deck and in the web app, and automatic view change (checked in game on the Prospector and the Arrow, Star Citizen 5.0 PTU).

🎬 Demo: https://youtu.be/t30sASa_oD4

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — Stream Deck (Ship Display)**
- **Weapons ready to fire**: "1 / 2" with a colored gauge (green: all ready, orange: some, red: none).
- **Active weapon group**: as in game — "All" for group 0, then 1, 2… (or the group's name if the game sends one).
- **Gimbals**: locked / free.
- "—" when the character is not seated or the seat has no weapons. Display only: the game exposes no command to change the weapon group or lock gimbals (weapon power stays available in Ship Toggle).

**New — web app**
- **Weapons ready**, **Weapon group** and **Gimbals** instruments in the *Ship* tab, the public API and the views' *Add* menu.
- **🔁 Auto — automatic view change** (per device): opens the chosen tab or view when your character is on foot, seated or in EVA. By default: on foot → *Character* tab, seated → *Ship* tab. Switches after 2 s in the same position, never while you edit a view; a tab you pick by hand is kept until your next change of position.

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.6** — armes, groupe d'armes et cardans sur le Stream Deck et dans l'appli web, et changement de vue automatique (vérifié en jeu sur le Prospector et l'Arrow, Star Citizen 5.0 PTU).

🎬 Démo : https://youtu.be/t30sASa_oD4

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — Stream Deck (Ship Display)**
- **Armes prêtes à tirer** : « 1 / 2 » avec une jauge colorée (vert : toutes prêtes, orange : une partie, rouge : aucune).
- **Groupe d'armes actif** : comme en jeu — « Toutes » pour le groupe 0, puis 1, 2… (ou le nom du groupe si le jeu en envoie un).
- **Cardans** : fixes / libres.
- « — » si le perso n'est pas assis ou si le siège n'a pas d'arme. Affichage seulement : le jeu n'expose aucune commande pour changer de groupe d'armes ou verrouiller les cardans (la puissance des armes reste dans Ship Toggle).

**Nouveau — appli web**
- Instruments **Armes prêtes**, **Groupe d'armes** et **Cardans** dans l'onglet *Vaisseau*, l'API publique et le menu *Ajouter* des vues.
- **🔁 Auto — changement de vue automatique** (par appareil) : ouvre l'onglet ou la vue choisie quand ton perso est à pied, assis ou en EVA. Par défaut : à pied → onglet *Personnage*, assis → onglet *Vaisseau*. Bascule après 2 s dans la même position, jamais pendant que tu modifies une vue ; un onglet choisi à la main est gardé jusqu'à ton prochain changement de position.

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.

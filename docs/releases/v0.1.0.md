**SC Telemetry Deck 0.1.0** — first Stream Deck plugin for Star Citizen, built on the game's local telemetry API (5.0 PTU, build 13238477).

- **Actor Action**: triggers a character action (mobiGlas, flashlight, star map, visor wipe) or an emote (34), picked from a grouped "Character" / "Emotes" list.
- **Morse Code**: flashes the flashlight in Morse code (text, dot length, repetitions). The flashlight must be off at start.

**Requirements**: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`, Stream Deck 7.1 or later.

**Install**: double-click `com.sokren.sc-telemetry.streamDeckPlugin`.

**Known issue**: in 5.0 PTU, the game accepts the `mobiglas` action but does not open the mobiGlas.

**SC Telemetry Deck 0.1.0** — premier plugin Stream Deck pour Star Citizen, via l'API de télémétrie locale du jeu (5.0 PTU, build 13238477).

- **Actor Action** : déclenche une action du perso (mobiGlas, torche, carte stellaire, visière) ou une émote (34), choisie dans une liste groupée « Personnage » / « Émotes ».
- **Morse Code** : fait clignoter la torche en morse (texte, durée d'un point, répétitions). La torche doit être éteinte au départ.

**Prérequis** : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`, Stream Deck 7.1 ou plus.

**Installation** : double-cliquer sur `com.sokren.sc-telemetry.streamDeckPlugin`.

**Limite connue** : en 5.0 PTU, le jeu accepte l'action `mobiglas` mais n'ouvre pas le mobiGlas.

**EN — SC Telemetry Deck 0.3.4** — your own views in the web app, tablet / phone access with a QR code, About window.

🎬 Demo: https://youtu.be/t30sASa_oD4

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — web app**
- **Your views**: build your own tabs (first one: **My view**; **＋** adds more, up to 10). Named sections (half or full width) and items picked from an **Add** menu: vitals, instruments, warning lights, ship functions, actions, emotes. Drag and drop with the mouse or a finger, 1× / 2× sizes. Unlock with the padlock to edit, rename or delete; lock to use. Views are saved in the app and kept when it restarts — one view per screen.
- **Tablet / phone** (📱 button, on the PC only): turn on access from the local network, then scan the **QR code** with the tablet (same Wi-Fi). **Open on** picks the view the link opens. The QR code and the full address are **hidden** every time the window opens — no IP on screen, handy when streaming; **Copy link** works even while hidden. **New token** disconnects every other device. Connected devices are counted, never shown by address.
  - Off by default. On: this PC plus the chosen network card (virtual cards — WSL, Hyper-V, VirtualBox, VPN… — are left out). Only the PC can change these settings.
  - The connection is **not encrypted** and the link contains the token: use it at home, not on public Wi-Fi. The first time, Windows may ask to allow the app through the firewall: tick **Private networks**.
  - Advanced option, **at your own risk**: **Listen on all interfaces (0.0.0.0)**, with a warning and a confirmation.
- **About** window: app version, checked game version, actions available or not, links to GitHub.
- A link ending in `?view=<id>` opens a given view directly; on a phone, the tabs become a list.

**Public API** (contract 1.2.0): `/api/v1/views` (list, create, save, delete — each view saved on its own), `/api/v1/lan`, `/api/v1/lan/token`, `/api/v1/lan/qr` (PC only); new `views` event.

**Third-party**: QR codes made with [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT), built into the exe.

**Downloads**: `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in) and `com.sokren.sc-telemetry.streamDeckPlugin` (unchanged since 0.3.2, attached again for convenience).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.4** — tes propres vues dans l'appli web, accès tablette / téléphone par QR code, fenêtre « À propos ».

🎬 Démo : https://youtu.be/t30sASa_oD4

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — appli web**
- **Tes vues** : compose tes propres onglets (le premier : **Ma vue** ; **＋** en ajoute, jusqu'à 10). Sections nommées (demi ou pleine largeur) et cases choisies dans un menu **Ajouter** : constantes, instruments, voyants, fonctions du vaisseau, actions, émotes. Glisser-déposer à la souris ou au doigt, tailles 1× / 2×. Déverrouille avec le cadenas pour modifier, renommer ou supprimer ; verrouille pour utiliser. Les vues sont enregistrées dans l'appli et gardées au redémarrage — une vue par écran.
- **Tablette / téléphone** (bouton 📱, sur le PC seulement) : active l'accès depuis le réseau local, puis scanne le **QR code** avec la tablette (même Wi-Fi). **Ouvrir sur** choisit la vue que le lien ouvre. Le QR code et l'adresse complète sont **masqués** à chaque ouverture de la fenêtre — aucune IP à l'écran, pratique si tu streames ; **Copier le lien** marche même masqué. **Nouveau jeton** déconnecte tous les autres appareils. Les appareils connectés sont comptés, jamais affichés par adresse.
  - Désactivé par défaut. Activé : ce PC plus la carte réseau choisie (les cartes virtuelles — WSL, Hyper-V, VirtualBox, VPN… — sont écartées). Seul le PC peut changer ces réglages.
  - La connexion **n'est pas chiffrée** et le lien contient le jeton : à utiliser chez toi, pas sur un Wi-Fi public. La première fois, Windows peut demander d'autoriser l'appli dans le pare-feu : coche **Réseaux privés**.
  - Option avancée, **à tes risques** : **Écouter sur toutes les interfaces (0.0.0.0)**, avec avertissement et confirmation.
- Fenêtre **À propos** : version de l'appli, version du jeu vérifiée, actions disponibles ou non, liens vers GitHub.
- Un lien finissant par `?view=<id>` ouvre directement une vue ; sur téléphone, les onglets deviennent une liste.

**API publique** (contrat 1.2.0) : `/api/v1/views` (lister, créer, enregistrer, supprimer — chaque vue enregistrée séparément), `/api/v1/lan`, `/api/v1/lan/token`, `/api/v1/lan/qr` (PC seulement) ; nouvel événement `views`.

**Tiers** : QR codes faits avec [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT), intégré à l'exe.

**Téléchargements** : `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré) et `com.sokren.sc-telemetry.streamDeckPlugin` (inchangé depuis la 0.3.2, joint à nouveau pour plus de commodité).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.

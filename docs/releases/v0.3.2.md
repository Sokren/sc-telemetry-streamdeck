**EN — SC Telemetry Deck 0.3.2** — clear message when the game version can't trigger actions (Star Citizen 5.0 PTU, build 13238477; display also works on 4.10).

🎬 Demo: https://youtu.be/t30sASa_oD4

**New**
- **Older game versions (e.g. 4.10)**: the telemetry exists there, but not the action commands (added in 5.0). This is now detected through the game's API alone — nothing is read or changed on Windows.
  - **Stream Deck**: a key pressed on such a version shows ⚠ and the plugin log says *actions not available with this game version (Star Citizen 5.0 required)*. Displays (vitals, ship state) keep working.
  - **Web app**: a banner explains that information display works but buttons don't.
  - **API**: `GET /api/v1/status` and the `status` event now include `actions` (`available` / `unsupported` / `unknown`). API contract 1.1.0 (additive).

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Requirements**: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg` (or `LIVE\user.cfg`, see README).

🇫🇷 **FR — SC Telemetry Deck 0.3.2** — message clair quand la version du jeu ne permet pas de déclencher d'actions (Star Citizen 5.0 PTU, build 13238477 ; l'affichage fonctionne aussi en 4.10).

🎬 Démo : https://youtu.be/t30sASa_oD4

**Nouveau**

  - **Stream Deck** : une touche pressée sur une telle version affiche ⚠ et le journal du plugin indique *actions non disponibles avec cette version du jeu (Star Citizen 5.0 requis)*. Les afficheurs (constantes, état du vaisseau) continuent de fonctionner.
  - **Appli web** : un bandeau explique que l'affichage des informations fonctionne, mais pas les boutons.
  - **API** : `GET /api/v1/status` et l'événement `status` contiennent maintenant `actions` (`available` / `unsupported` / `unknown`). Contrat d'API 1.1.0 (ajout uniquement).

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour l'installer dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Prérequis** : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg` (ou `LIVE\user.cfg`, voir le README).

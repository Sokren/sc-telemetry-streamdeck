**EN — SC Telemetry Deck 0.3.0** — ship controls with live state, and a standalone web app (Star Citizen 5.0 PTU, build 13238477).

🎬 Demo: https://youtu.be/t30sASa_oD4

**New on Stream Deck**
- **Ship Toggle**: 17 ship functions with their live state — landing gear, lights, VTOL, transformation, decoupled, G-safe, proximity assist, ESP, advanced HUD, night vision, NAV/SCM, engine / weapon / shield power, main power, doors. Per key: mode (toggle based on the state read, on only, off only) and style (A text, B LED, C filled). "—" outside a ship.
- **Ship Action**: every ship and seat command (flight ready, ATC, ping, quantum, seat modes…). On / off / toggle commands of a same function are merged into one entry with a mode setting; existing keys are converted automatically.
- Dangerous actions (self destruct, eject, power off, opening / unlocking doors) are never offered nor sent.

**New: standalone web app (preview)** — for players without a Stream Deck
- Button grid, **Character** tab (position, crew role, all 13 vitals) and **Ship** tab (instruments, warning lights, clickable functions), live, in French and English.
- Documented public API (OpenAPI / Swagger at `/api/docs`, with search) to build your own tools. Token required; this PC only for now.
- Install: unzip `sc-telemetry-web-0.3.0.zip`, run `node server.mjs` in that folder (Node.js 24 required for now; a single `.exe` will come later).

**Requirements**: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg` (see README), Stream Deck 7.1 or later for the plugin.

**Known issues**: in 5.0 PTU the game accepts `mobiglas` but does not open the mobiGlas. Quantum fuel may read 0 % on some ships (to be checked in game).

🇫🇷 **FR — SC Telemetry Deck 0.3.0** — commandes vaisseau avec état réel, et une appli web autonome (Star Citizen 5.0 PTU, build 13238477).

🎬 Démo : https://youtu.be/t30sASa_oD4

**Nouveau sur Stream Deck**
- **Ship Toggle** : 17 fonctions vaisseau avec leur état réel — train, phares, VTOL, transformation, découplage, G-safe, assistance de proximité, ESP, HUD avancé, vision nocturne, NAV/SCM, puissance moteurs / armes / boucliers, puissance générale, portes. Par touche : mode (bascule selon l'état lu, allumer seulement, éteindre seulement) et style (A texte, B voyant, C fond coloré). « — » hors du vaisseau.
- **Ship Action** : toutes les commandes vaisseau et siège (prêt au vol, ATC, ping, quantum, modes du siège…). Les commandes on / off / bascule d'une même fonction sont regroupées en une ligne avec un réglage de mode ; les touches existantes sont converties automatiquement.
- Les actions dangereuses (autodestruction, éjection, coupure de la puissance, ouverture / déverrouillage des portes) ne sont jamais proposées ni envoyées.

**Nouveau : appli web autonome (aperçu)** — pour les joueurs sans Stream Deck
- Grille de boutons, onglet **Personnage** (position, rôle, les 13 constantes) et onglet **Vaisseau** (instruments, voyants, fonctions cliquables), en direct, en français et en anglais.
- API publique documentée (OpenAPI / Swagger sur `/api/docs`, avec recherche) pour créer tes propres outils. Jeton exigé ; ce PC seulement pour l'instant.
- Installation : décompresser `sc-telemetry-web-0.3.0.zip`, lancer `node server.mjs` dans ce dossier (Node.js 24 nécessaire pour l'instant ; un `.exe` unique viendra plus tard).

**Prérequis** : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg` (voir le README), Stream Deck 7.1 ou plus pour le plugin.

**Limites connues** : en 5.0 PTU, le jeu accepte `mobiglas` mais n'ouvre pas le mobiGlas. Le carburant quantum peut afficher 0 % sur certains vaisseaux (à vérifier en jeu).

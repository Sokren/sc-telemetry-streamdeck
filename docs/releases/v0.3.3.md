**EN — SC Telemetry Deck 0.3.3** — all emotes in the web app, version shown on the page, 4.10.3 LIVE setup (Star Citizen 5.0 PTU, build 13248297).

🎬 Demo: https://youtu.be/t30sASa_oD4

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — web app**
- **All player emotes** in the **Character** tab: one button per emote (34), read live from the game, sorted by name, ✔ / ⚠ when pressed.
- **App version** shown next to the title; hover it to see the game version of the embedded schema.

**Docs**
- **Star Citizen 4.10.3 (LIVE)**: telemetry is enabled with one PowerShell command, `setx GRPC_CLIENT_SERVER_ENABLED true`, then start the RSI Launcher and the game. Information display works; actions need 5.0.
- Beta notice and per-version limits in the README.

**Game**: schema checked on PTU build 13248297 (5.0.202.10025) — identical to the previous build (schema, 112 actions, 948 command names).

**Downloads**: `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in) and `com.sokren.sc-telemetry.streamDeckPlugin` (unchanged since 0.3.2, attached again for convenience).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

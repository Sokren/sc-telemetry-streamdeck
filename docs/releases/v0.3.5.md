**EN — SC Telemetry Deck 0.3.5** — your ship's countermeasures on the Stream Deck and in the web app (checked in game on the Prospector, Star Citizen 5.0 PTU).

🎬 Demo: https://youtu.be/t30sASa_oD4

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — Stream Deck**
- **Ship Display**: the ship's **countermeasures**, live — decoys and noise together ("45 / 3"), or one of them.
  - On a key: count + colored gauge (green ≥ 50 %, orange 25–50 %, red < 25 %). On a Stream Deck + dial: touchscreen, **rotate to change the value**.
  - The game does not send the maximum stock: 100 % = the largest stock seen for this ship model while a display is visible.
  - "—" when the game is closed, the character is not seated, or the ship has no countermeasure of that type.
  - Display only: the game exposes no command to fire countermeasures.

**New — web app**
- **Decoys** and **Noise** instruments in the *Ship* tab, the public API (`/api/v1/ship/status`, `state` event) and the views' *Add* menu.

**Docs**: full changelog since 0.1.0 in `CHANGELOG.md` / `CHANGELOG.fr.md`, linked from the README.

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.5** — les contre-mesures de ton vaisseau sur le Stream Deck et dans l'appli web (vérifié en jeu sur le Prospector, Star Citizen 5.0 PTU).

🎬 Démo : https://youtu.be/t30sASa_oD4

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — Stream Deck**
- **Ship Display** : les **contre-mesures** du vaisseau en direct — leurres et brouilleurs ensemble (« 45 / 3 »), ou l'un des deux.
  - Sur une touche : nombre + jauge colorée (vert ≥ 50 %, orange 25–50 %, rouge < 25 %). Sur une molette de Stream Deck + : écran tactile, **tourner pour changer de donnée**.
  - Le jeu n'envoie pas le stock maximal : 100 % = le plus grand stock vu pour ce modèle de vaisseau pendant qu'un afficheur est visible.
  - « — » si le jeu est fermé, le perso pas assis, ou le vaisseau sans ce type de contre-mesure.
  - Affichage seulement : le jeu n'expose aucune commande pour lancer des contre-mesures.

**Nouveau — appli web**
- Instruments **Leurres** et **Brouilleurs** dans l'onglet *Vaisseau*, l'API publique (`/api/v1/ship/status`, événement `state`) et le menu *Ajouter* des vues.

**Documentation** : journal complet des modifications depuis la 0.1.0 dans `CHANGELOG.md` / `CHANGELOG.fr.md`, lié depuis le README.

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.

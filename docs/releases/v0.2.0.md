**SC Telemetry Deck 0.2.0** — character vitals on your keys and Stream Deck + dials (Star Citizen 5.0 PTU, build 13238477).

**New: Actor Display**
- Shows a character vital, live: health, oxygen, hunger, thirst, body / outside temperature, heart rate, gravity, pressure, radiation, intoxication, breathable air, balance.
- **Key**: value + colored gauge (green ≥ 50 %, orange 25–50 %, red < 25 %; body temperature green between 35 and 38 °C).
- **Stream Deck + dial**: label, value and gauge on the touchscreen; **rotate the dial to change the value**.
- "—" when the game is closed or the character has not spawned yet; values come back on their own when the game restarts.
- A single telemetry stream is shared by all displays and only opened while one is visible.

**Also included**: Actor Action and Morse Code from 0.1.0.

**Requirements**: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`, Stream Deck 7.1 or later.

**Install / update**: double-click `com.sokren.sc-telemetry.streamDeckPlugin`.

**Known issues**: in 5.0 PTU the game accepts `mobiglas` but does not open the mobiGlas. Long labels may be tight on the dial screen.

**SC Telemetry Deck 0.2.0** — les constantes du perso sur tes touches et les molettes du Stream Deck + (Star Citizen 5.0 PTU, build 13238477).

**Nouveau : Actor Display**
- Affiche une constante du perso en continu : santé, oxygène, faim, soif, température corporelle / extérieure, rythme cardiaque, gravité, pression, rayonnement, intoxication, atmosphère respirable, solde.
- **Touche** : valeur + jauge colorée (vert ≥ 50 %, orange 25–50 %, rouge < 25 % ; température corporelle verte entre 35 et 38 °C).
- **Molette du Stream Deck +** : libellé, valeur et jauge sur l'écran tactile ; **tourner la molette change la donnée affichée**.
- « — » quand le jeu est fermé ou le perso pas encore apparu ; les valeurs reviennent seules quand le jeu redémarre.
- Un seul flux de télémétrie partagé par tous les afficheurs, ouvert seulement quand l'un d'eux est visible.

**Toujours là** : Actor Action et Morse Code de la 0.1.0.

**Prérequis** : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`, Stream Deck 7.1 ou plus.

**Installation / mise à jour** : double-cliquer sur `com.sokren.sc-telemetry.streamDeckPlugin`.

**Limites connues** : en 5.0 PTU, le jeu accepte `mobiglas` mais n'ouvre pas le mobiGlas. Les libellés longs sont un peu serrés sur l'écran des molettes.

**EN — SC Telemetry Deck 0.3.1** — the web app is now a single executable (Star Citizen 5.0 PTU, build 13238477).

🎬 Demo: https://youtu.be/t30sASa_oD4

**New**
- **`sc-telemetry-web.exe`**: the standalone web app in one file — nothing to install, no Node.js needed. Double-click it and the page opens in your browser (Grid, Character and Ship tabs, documented API at `/api/docs`).
- After a game patch, drop an updated `sc_extrait.desc` / `actions.json` next to the exe: it uses them instead of the embedded ones.

**Note**: the exe isn't signed — Windows SmartScreen may warn the first time: *More info → Run anyway*.

**Stream Deck plugin**: unchanged since 0.3.0 (attached again for convenience).

**Requirements**: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg` (see README).

**Nouveau**
- **`sc-telemetry-web.exe`** : l'appli web autonome en un seul fichier — rien à installer, pas besoin de Node.js. Double-clique dessus et la page s'ouvre dans ton navigateur (onglets Grille, Personnage et Vaisseau, API documentée sur `/api/docs`).

**Prérequis** : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg` (voir le README).

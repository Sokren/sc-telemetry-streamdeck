Stream Deck + : tourner la molette change la donnée affichée. « — » : jeu fermé, perso pas assis, ou vaisseau sans ce type de contre-mesure ou sans arme. Contre-mesures : 100 % = le plus grand stock vu pour ce modèle de vaisseau pendant qu'un afficheur est visible (le jeu ne donne pas le maximum). Affichage seulement : le jeu ne permet ni de lancer des contre-mesures, ni de changer de groupe d'armes, ni de verrouiller les cardans depuis une touche.
Stream Deck +: rotate the dial to change the value. "—": game closed, character not seated, or ship without this countermeasure type or without weapons. Countermeasures: 100% = the largest stock seen for this ship model while a display is visible (the game does not send the maximum). Display only: the game does not allow firing countermeasures, changing the weapon group or locking gimbals from a key.
